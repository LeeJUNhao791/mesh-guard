# v0.3.1 release notes

Documentation patch for the existing Mesh Guard v0.3.0 checker and GitHub Action.

- Surface the existing millimeter PASS and meter FAIL Action screenshots near the top of both READMEs.
- Explain the v0.3.0 Action workflow, job summaries, JSON report retention, and separate dimension-checking scope.
- Document the downstream mounting-plate digital dimension trial, including passing and oversized STL reports.
- Add contributor checks and a pull request template; exclude local dependency and OS artifacts.

The STL parser, CLI, browser checker, Action wrapper, and Action metadata are unchanged from v0.3.0. Existing README examples remain pinned to the published v0.3.0 Action until the new release is available.

## Validation and limits

Run the existing suite with Node.js 22:

```sh
node --test tests/test_stl.mjs tests/test_cli.mjs tests/test_action.mjs
```

The tests cover parsing, CLI results, and local Action wrapper behavior. Earlier hosted Action evidence and downstream reports retain their original versions and dates. This documentation patch adds no new hosted execution or manufacturing evidence. A dimension PASS checks digital overall X/Y/Z spans against a reference and tolerance; it does not prove internal features, printability, or physical manufacturing accuracy.
